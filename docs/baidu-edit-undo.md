# 百度输入法编辑面板撤销与重做

适配百度输入法 `com.baidu.input` 13.3.23.25（versionCode 1192）。
开启百度输入法作用域后生效，更新模块后需重启输入法进程。

## 实现方式

编辑面板由 `EditControlManagerDelegate` 自绘，不使用 XML 按钮布局。
模块在 `t()` 完成原生按键布局后，向其 `KeymapPopupView` 添加两个普通文字按钮；
在 `n(Canvas)` 绘制后，使用 `w0`、`x0` 两个行首、行尾按钮的位置计算中间空白，
并减去面板纵向偏移 `k`，使按钮跟随键盘尺寸变化。
边框与文字使用原面板的颜色，按下显示圆形波纹。
面板释放时通过 `H()` 移除新增按钮。

只在圆形光标布局（`C0` 为 5 或 6）中显示按钮，其他布局没有对应空白，因此不插入。
新增按钮使用独立子控件处理点击，不修改原生按键数组、命中检测和长按行为。

点击分别通过当前 `InputConnection.performContextMenuAction()` 发送
`android.R.id.undo` 或 `android.R.id.redo`，不维护输入法自己的历史。
撤销范围和合并粒度由目标编辑器决定；没有历史或不支持该操作的编辑器可能没有反应。
该接口返回 `true` 不能证明文本已经变化，因此不根据返回值追加其他撤销方式。
